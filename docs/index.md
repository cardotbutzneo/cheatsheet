# Programming Cheat Sheets

Welcome!   
This site is a collection of concise, practical notes on the languages and concepts I use while studying.
Each page is meant to be a quick reference: short explanations, runnable examples, and the common pitfalls that cost time when you start.

## What's inside

| Page | Content |
|:-----|:--------|
| [Python](Python/python.md) | Variables, conditions, lists, functions, classes, sorting |
| [Python data structures](Python/data_structures.md) | Built-in structures, stacks, queues, heaps, trees, hash tables |
| [C data structures](C/complex_strucuts.md) | Linked lists, stacks, queues, BST, AVL trees, hash tables |
| [Pseudocode](pseudo-code/start.md) | Writing algorithms in French and English notation |
| [Bash](Bash/start.md) | Variables, tests, loops, functions, redirections, essential commands |

## How to use these notes

- **Looking for something specific?** Use the search bar at the top.
- **Learning a topic from scratch?** Read the pages in order, from top to bottom.
- **Comparing languages?** The data structure pages follow the same outline in C and Python, so you can read them side by side.

All code examples are meant to be copied, run and modified.

## Getting started

Clone the repository:

~~~bash
git clone https://github.com/cardotbutzneo/cheatsheet
~~~

Install MkDocs and preview the site locally:

~~~bash
pip install mkdocs
mkdocs serve
~~~

Then open <http://127.0.0.1:8000> in your browser. The page reloads automatically when you edit a file.

To build the static site:

~~~bash
mkdocs build
~~~

To publish it on GitHub Pages:

~~~bash
mkdocs gh-deploy
~~~
