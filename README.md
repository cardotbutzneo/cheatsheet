# ChearSheet

Welcome to my little collection of programming cheatsheets!

I can't count how many times I've forgotten a data structure, a function, or some syntax and had to ask an AI or dig through the documentation to find it.

Sometimes, I just want to copy and paste a built-in function, a data structure, or a small code snippet without spending half an hour looking for it.

That's the goal of this repository: small, practical cheatsheets for the programming languages and technologies I use.

I also enjoy sharing the knowledge I've picked up with people who may not know a language or a concept yet. If you're here just to have a look, or if you want to contribute, thank you! I hope you find what you're looking for.

# Overview

This repository contains cheatsheets for several programming languages and technologies.

Each cheatsheet focuses on the things I personally find useful to remember:

- Common syntax
- Built-in functions
- Data structures
- Useful code snippets
- Common patterns
- Language-specific concepts
- Small examples
- Things that are easy to forget

The goal is `not` to cover everything. These cheatsheets are meant to be quick references, not complete documentation.

# Looking for complete documentation?
If you need detailed or official documentation, you should use the official documentation of the language or library you're working with.

Here are also a couple of useful resources:

Cheatsheets.zip — A collection of programming cheatsheets.  
Koor.fr — French programming resources and documentation...  
Or just the official documentation for the language you use!  
Disclaimer: This repository is not official documentation for any of the languages or technologies covered here.  
I may make mistakes, miss important details, or simplify some concepts for the sake of readability.

**When in doubt, always prefer the official documentation.**

# Contributing 

If you find a mistake, something outdated, or something that could be explained better, feel free to open an issue or submit a pull request.

Contributions are welcome!

Whether you're fixing a typo, correcting a technical mistake, adding a useful example, or creating a cheatsheet for another language, every contribution is appreciated.

# So why this repository?

Because sometimes you don't need a 500-page documentation.

Sometimes you just need:

*"How the hell do I sort this thing again?"*

And hopefully somethimes a quick look at a cheat sheet is enough.
